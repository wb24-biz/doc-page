# Ролі користувачів

:::warning
Этот раздел ещё не переведён.
:::

Розділ **Ролі користувачів** визначає набори прав, які можна призначити обліковим записам. Кожна роль містить перелік дозволених дій (перегляд, створення, редагування, видалення) у межах конкретних розділів панелі.

Стандартний набір ролей включає, наприклад: «Адміністратор», «Оператор», «Бухгалтер», «Тільки перегляд». За потреби можна створювати власні ролі з тонко налаштованими правами.

При зміні прав ролі зміни застосовуються одразу до всіх користувачів, що мають цю роль — будьте уважні при редагуванні ролей у робочій системі.

Призначення ролей відбувається в розділі **[Користувачі](./users)**. Один користувач може мати кілька ролей — у такому випадку його дозволи об'єднуються.
