# Еквайринг

:::warning
Этот раздел ещё не переведён.
:::

Розділ **Еквайринг** призначений для налаштування платіжних провайдерів, через які приймаються безготівкові оплати на автоматах. Підтримуються провайдери LiqPay та Monobank; перелік може розширюватися.

Для кожного провайдера зберігаються облікові дані (ключі API, ідентифікатори торгової точки) та налаштування, як-от валюта операцій, URL вебхуків, режим тестування. Конфігурація може застосовуватись до окремих автоматів або груп.

Для коректної роботи провайдера переконайтеся, що ключі активні в кабінеті провайдера, а вебхук-URL зареєстрований і доступний з інтернету.

Курс валют для перерахунку (наприклад, EUR→UAH для еквайрингу) бере НБУ автоматично — додатково налаштовувати не потрібно.
