# Користувачі

:::note
Чернетка — потребує доопрацювання.
:::

Розділ **Користувачі** містить список облікових записів, що мають доступ до адмін-панелі. Тут можна додавати нових користувачів, редагувати їхні дані, призначати ролі та робочі групи.

Створення нового користувача потребує вказання логіна, електронної пошти та початкового пароля. Пароль рекомендується змінити при першому вході — система може запитати це автоматично, якщо налаштовано відповідну політику.

Деактивація облікового запису забороняє вхід без видалення історії дій користувача — це безпечніше, ніж повне видалення, особливо якщо користувач створював замовлення або інші об'єкти в системі.

Для масової роботи (наприклад, додавання багатьох операторів) корисно спочатку налаштувати потрібні **[Ролі](./user-roles)** та **[Робочі групи](./work-groups)**, а потім присвоювати їх новим користувачам.
