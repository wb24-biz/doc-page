# Автомати

:::warning
This section has not been translated yet.
:::

Розділ **Автомати** містить реєстр усіх вендингових пристроїв, підключених до системи. Тут відображається список автоматів зі статусом (онлайн/офлайн), поточною прошивкою, прив'язкою до робочих груп і географічним розташуванням.

З цієї сторінки можна додавати нові автомати, редагувати їхні параметри, призначати тарифи, налаштовувати рецепти та інгредієнти, переглядати журнал транзакцій конкретного пристрою.

Фільтри над списком дозволяють швидко знайти автомат за назвою, типом, статусом або групою. Для масових операцій (наприклад, оновлення прошивки) скористайтеся виділенням кількох пристроїв.

Пов'язані розділи: **[Типи автоматів](./machine-types)** — довідник конфігурацій обладнання, **[Прошивки](./firmwares)** — керування версіями ПЗ.
