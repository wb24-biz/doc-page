# Робочі групи

:::warning
Этот раздел ещё не переведён.
:::

Розділ **Робочі групи** дозволяє об'єднувати автомати в логічні групи для зручного керування — наприклад, за географією, типом точки розташування, або за відповідальним оператором.

Робоча група може використовуватись як фільтр у звітах і списках, як основа для масових операцій (оновлення прошивки, призначення тарифу) або як механізм обмеження доступу: користувач, прив'язаний до групи, бачить лише її автомати.

Один автомат може належати до однієї робочої групи; для багатовимірної категоризації доцільно поєднувати робочі групи з тегами або типами автоматів.

Перейменування робочої групи безпечне і не порушує посилання — система використовує внутрішні ідентифікатори, незалежні від назви.
