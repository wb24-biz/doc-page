# Чеки

:::warning
Этот раздел ещё не переведён.
:::

Розділ **Чеки** містить історію фіскальних чеків, виданих за платежами клієнтів. Кожен чек має унікальний номер, дату, суму, перелік позицій і статус (виданий/анульований).

Чеки формуються автоматично через інтеграцію з фіскальним сервісом — налаштування цієї інтеграції описано у розділі **[Фіскалізація](./fiscalization)**.

З цієї сторінки можна повторно надіслати чек клієнту електронною поштою, переглянути PDF-версію або скопіювати посилання на онлайн-чек у фіскальному сервісі.

У разі помилки видачі чека відображається відповідний статус і причина — це допомагає швидко виявити проблеми з фіскальним обладнанням або налаштуваннями.
