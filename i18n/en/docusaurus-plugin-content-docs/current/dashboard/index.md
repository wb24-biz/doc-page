# Огляд мережі

:::warning
This section has not been translated yet.
:::

Розділ **Огляд** — це стартова сторінка адмін-панелі. На ній зведено ключові показники мережі автоматів: загальна виручка, кількість продажів, активні та неактивні пристрої.

Дані оновлюються в режимі, близькому до реального часу. Період відображення даних можна змінити у фільтрі вгорі сторінки — наприклад, переглянути показники за день, тиждень або місяць.

Картки на сторінці слугують точками входу до деталізованих звітів: натискання на картку «Замовлення» відкриває розділ з повним списком транзакцій, аналогічно для платежів та автоматів.

Для глибшого аналізу скористайтеся розділом **[Статистика](./statistics)** — там доступні детальні графіки та зрізи даних.
