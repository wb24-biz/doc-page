# Платежі

:::warning
This section has not been translated yet.
:::

Розділ **Платежі** показує всі фінансові транзакції, що пройшли через систему: успішні оплати, повернення коштів, незавершені або скасовані спроби.

Кожен платіж пов'язаний із замовленням і конкретним платіжним провайдером (LiqPay, Monobank тощо). Статус платежу оновлюється автоматично за вебхуками від провайдера; ручне втручання потрібне рідко.

Фільтри дозволяють відібрати платежі за провайдером, статусом, періодом або сумою. Це корисно при звірці з банківськими виписками або розслідуванні спірних операцій.

Пов'язані розділи: **[Еквайринг](./acquiring)** — налаштування платіжних провайдерів, **[Фіскалізація](./fiscalization)** — інтеграція з фіскальними сервісами, **[Чеки](./checks)** — фіскальні чеки за здійсненими операціями.
