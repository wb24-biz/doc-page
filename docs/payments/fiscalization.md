# Фіскалізація

:::note
Чернетка — потребує доопрацювання.
:::

Розділ **Фіскалізація** містить налаштування інтеграції з фіскальними сервісами для автоматичної видачі чеків після кожної оплати. На сьогодні підтримується сервіс vChasno; список провайдерів може розширюватися.

Для кожної конфігурації зберігаються облікові дані фіскального сервісу, ідентифікатор каси, реквізити продавця, які друкуються на чеках. Конфігурація прив'язується до автомата або групи автоматів.

Якщо фіскалізація відключена для автомата, чеки за його продажами не формуються — це може бути потрібно, наприклад, для тестових пристроїв або режимів роботи без обов'язкової фіскалізації.

Згенеровані чеки доступні у розділі **[Чеки](./checks)**, де також відображаються можливі помилки інтеграції з фіскальним сервісом.
