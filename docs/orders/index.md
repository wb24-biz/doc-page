# Замовлення

:::note
Чернетка — потребує доопрацювання.
:::

Розділ **Замовлення** містить повну історію продажів через мережу автоматів. Кожен запис відповідає одній транзакції клієнта: вибраний продукт, обсяг, сума, час, автомат, спосіб оплати.

Список можна фільтрувати за періодом, автоматом, способом оплати або статусом замовлення. Підсумкові показники (загальна сума, кількість) відображаються над таблицею.

Натискання на конкретне замовлення відкриває деталі: повний журнал подій, зв'язаний платіж, дані фіскального чека (якщо застосовувалась фіскалізація).

Експорт замовлень у Excel доступний кнопкою у правому верхньому куті — корисно для бухгалтерського обліку або зовнішнього аналізу. Для оформлення нових замовлень оператором передбачена сторінка **[Оформлення](./ordering)**.
