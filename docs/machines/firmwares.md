# Прошивки

:::note
Чернетка — потребує доопрацювання.
:::

Розділ **Прошивки** дозволяє керувати версіями програмного забезпечення для автоматів. Тут можна завантажувати нові прошивки, переглядати історію версій та призначати оновлення для конкретних пристроїв або груп.

Оновлення прошивки виконується дистанційно: після призначення версії автомат отримує її при наступному сеансі зв'язку. Процес оновлення супроводжується контрольними сумами для уникнення пошкоджень.

Для безпеки нові прошивки рекомендується тестувати на одному-двох автоматах перед масовим розгортанням. Невдале оновлення може потребувати фізичного доступу до пристрою.

Список прошивок фільтрується за типом автомата, що гарантує сумісність — система не дозволить призначити прошивку на несумісну модель.
