# Тарифні плани

:::note
Чернетка — потребує доопрацювання.
:::

Розділ **Тарифні плани** дозволяє керувати правилами ціноутворення для продажів через автомати. Тариф визначає ціну за одиницю обсягу для кожного продукту і може враховувати додаткові параметри: час доби, день тижня, тип клієнта.

Один тариф може застосовуватись до кількох автоматів одночасно — це зручно для мережевого ціноутворення. Зміна тарифу набуває чинності одразу після збереження і поширюється на всі автомати, що його використовують.

Історія тарифних змін зберігається — це важливо для розрахунку виручки за минулі періоди, коли діяли інші ціни.

Платежі за використання самих тарифних планів (якщо тарифи на платформі тарифікуються окремо для оператора) обліковуються у розділі **[Платежі за тарифи](./tariff-payments)**.
