# Огляд

:::warning
This section has not been translated yet.
:::

Адмін-панель WB24 — це веб-додаток для керування мережею автоматів з продажу води. Доступ до панелі здійснюється через браузер; жодного встановлення на комп'ютер не потрібно.

Панель побудована як єдиноспрямований інтерфейс із бічним меню, що містить усі основні розділи: огляд, автомати, замовлення, платежі, тарифи та налаштування. Користувачі з різними ролями бачать лише ті розділи, доступ до яких надано адміністратором.

Перед початком роботи ознайомтеся з тим, як увійти до системи у розділі **[Вхід](./login)**. Після авторизації ви потрапляєте на оглядову сторінку з ключовими показниками мережі.

Якщо ви адміністратор системи, рекомендуємо також переглянути розділ **[Налаштування](../settings/)** — там керують користувачами, ролями, доменами та валютами.
