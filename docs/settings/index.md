# Налаштування

:::note
Чернетка — потребує доопрацювання.
:::

Розділ **Налаштування** об'єднує адміністративні інструменти платформи: керування користувачами, ролями, доменами, валютами та робочими групами.

Більшість налаштувань потрібні лише адміністраторам системи. Звичайні оператори бачать тут лише свій профіль та обмежений набір опцій.

Зміни в цьому розділі поширюються на всю систему: наприклад, зміна валюти за замовчуванням впливає на нові тарифи, а зміна ролі користувача — на його доступ до інших розділів панелі.

Підрозділи: **[Валюти](./currencies)**, **[Домени](./domains)**, **[Користувачі](./users)**, **[Ролі користувачів](./user-roles)**, **[Робочі групи](./work-groups)**.
