# Домени

:::warning
Этот раздел ещё не переведён.
:::

Розділ **Домени** використовується для логічного розділення мереж автоматів між різними організаціями або підрозділами в межах однієї платформи. Кожен домен має власні налаштування, користувачів і обмежений перелік автоматів.

Це корисно для великих операторів із кількома брендами, для франчайзингових мереж або для технічних доменів (наприклад, тестового середовища).

Користувач може мати доступ до одного або кількох доменів — вибір активного домену відбувається у меню профілю після входу до панелі.

Створення нових доменів зазвичай потребує погодження з адміністратором платформи; самостійно це робить лише супер-адміністратор системи.
