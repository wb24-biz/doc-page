# Вхід до панелі

:::warning
This section has not been translated yet.
:::

Доступ до адмін-панелі WaterBiz здійснюється через сторінку входу. Введіть видані вам облікові дані (логін та пароль) і натисніть «Увійти».

Якщо обліковий запис захищений двофакторною автентифікацією, після введення пароля з'явиться додаткове поле для одноразового коду. Код надсилається на прив'язаний канал сповіщень.

У разі втрати пароля зверніться до адміністратора вашого облікового запису — самостійне відновлення поки що не передбачене. Адміністратор може скинути пароль у розділі **[Користувачі](../settings/users)**.

Після успішного входу сесія зберігається до явного виходу або до закінчення терміну дії токена. Для виходу скористайтеся меню профілю у правому верхньому куті.
