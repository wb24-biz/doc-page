# Статистика

:::note
Чернетка — потребує доопрацювання.
:::

Розділ **Статистика** надає детальний аналітичний інструментарій для оцінки роботи мережі автоматів. На відміну від оглядової сторінки, тут доступні глибші зрізи даних і налаштовувані графіки.

Серед типових сценаріїв: порівняння виручки між автоматами або групами автоматів, аналіз пікових годин продажів, оцінка ефективності тарифних планів, відстеження сезонних коливань попиту.

Усі звіти можна експортувати в Excel для подальшої роботи поза панеллю — кнопка експорту знаходиться у правому верхньому куті кожного графіка.

Дані статистики формуються на основі завершених замовлень і успішних платежів. Незавершені або скасовані операції до звітів не потрапляють.
