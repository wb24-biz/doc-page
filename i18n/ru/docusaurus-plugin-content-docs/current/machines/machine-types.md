# Типи автоматів

:::warning
Этот раздел ещё не переведён.
:::

Розділ **Типи автоматів** — це довідник конфігурацій обладнання. Кожен тип описує модель автомата: підтримувані функції, набір сенсорів, параметри підключення та сумісні рецепти.

Під час додавання нового пристрою у розділ **[Автомати](./)** йому призначається один із наявних типів. Це визначає, які налаштування будуть доступні для цього автомата.

Створення власних типів зазвичай потрібне лише при підключенні нового модельного ряду обладнання. Для більшості користувачів достатньо стандартних типів, налаштованих адміністратором системи.

Зміна типу для вже зареєстрованого автомата може спричинити втрату специфічних налаштувань — будьте обережні з цією дією.
